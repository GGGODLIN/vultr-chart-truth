Forensic audit for AI-generated charts

The chart is a claim.The ledger is the proof.

AI-written charting code fails quietly: it hardcodes numbers when a parser chokes, sums a Total row twice, or obeys a note in the CSV that asks for your API key. ChartTruth runs that code in a zero-secret, network-less container, replays it on a ×3 shadow copy of the data, and re-adds every leaf row with an independent oracle before any chart gets out.
